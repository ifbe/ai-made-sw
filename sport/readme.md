# sport

球类对战 App：**足球 / 篮球 / 排球 / 乒乓球**四个页面。球场按**真实比例**画在屏幕正中，屏幕其余部分**纯黑**，场上的球员和球都能拖着走。

现在**足球**（105×68 米，22 人）和**篮球**（28×15 米，10 人）是真的，排球 / 乒乓球是占位页。

## 功能

- 左上角四个标签切换页面，右上角「重新摆位」把当前页摆回开球站位
- 球场按真实米数绘制：比例尺 = `min(屏幕短边 / 球场短边, 屏幕长边 × 0.8 / 球场长边)`，
  短边对齐 / 长边最多占 80%，所以球场外永远是黑的
- 拖动球员和球：拿起最近的令牌，松手停在哪儿就是哪儿（**没有任何规则判断** —— 不判越位、不判出界、不判进球、不记分）
- 局域网联机：左下角 `[服/客][地址][开始/状态]`，一台开服务、另一台填地址连过去；
  拖动过程实时同步，落位后同步整盘状态
- 右下角可折叠的 **app 内日志**（启动 / 切页 / 重置 / 拿起放下 / 收发），同一份也写到 logcat（tag `SportApp`）
