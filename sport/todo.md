# TODO / 已知缺口

按「现在缺什么 + 大概怎么做」记，优先级从高到低。

## 联机

- [ ] **前台服务 + partial wakelock**：现在只有「联机期间屏幕常亮」，息屏或切后台久了系统会冻结
      App，socket 就没人处理了（症状见 [gotcha.md](gotcha.md) 里「Android 16+ 访问局域网」那条）。
      做法可参考同目录的 `chatroom` 工程：有连接时 `startForeground`（`connectedDevice` 类型）
      + `PARTIAL_WAKE_LOCK`，全部断开后 `stopForeground + stopSelf`；再引导用户加电池优化白名单。
- [ ] **断线自动重连 + 心跳**：服务端主动 ping/pong，客户端断线后按退避重连，
      并在重连时用服务端缓存的最后一包 `state` 对齐（服务端已经有 `lastState` 缓存了）。
- [ ] **座位分配**：服务端告诉每个客户端「你是哪一方」，据此限制谁能动子（现在只按本地判断）。
- [ ] **房间号 / 口令 / 鉴权**：现在只要连上端口就能发事件，也能发任意坐标。
- [ ] **目标地址的 IP 也是端口一样可改但切页会重填**：`show()` 里会 `refreshNetAddress()`，
      客户端模式下会把正在编辑的地址冲掉。要么只在空的时候填，要么分出「本机地址」和「对端地址」两个框。
- [ ] **观众模式**：只收不发的连接（服务端广播时已经区分发送者，加个角色即可）。
- [ ] **IPv6**：现在显式绑 `0.0.0.0`（仅 IPv4），发给对端的也是 IPv4 地址。
