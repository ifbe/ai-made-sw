# test/ —— 参考实现的测试

**怎么跑**（在仓库根目录）：

```bash
python3 test/run_all.py         # 主入口：按 [0]~[11] 顺序全跑（约 1~2 分钟），最后打印"通过 N 项 / 失败 M 项"
python3 test/doccheck.py        # 只查文档一致性（很快）
python3 test/mixed.py           # 只跑混合粒度用例
python3 test/anchor_v3.py       # 只跑 anchor 布局用例
```

环境变量：

* `EASYFS_TEST_DIR` —— 改落盘目录（默认 `test/.work/`）；
* `EASYFS_TEST_KEEP=1` —— 跑完**保留**镜像（默认跑完就清掉；每次跑**开始时会清空**工作目录）。

**结果怎么读**：`通过 N 项 / 失败 0 项`、`ALL = True （N 项）`、`发现问题 0 个`、`全部通过 ✓`
—— 出现 `✗` 行就是失败项的名字。

## 资源纪律（**请遵守**，宿主机内存 / 磁盘有限）

* 落盘的卷一律 **≤ 1.5 GiB**，而且都是**稀疏文件**（实占几十 KB ~ 几百 KB）；
* 1 TiB / 16 TiB / 2 PiB 这类大卷**只用 `plan_layout` / `find_best_alloc_setting` 纯算** ——
  位图选型本来就是个公式，不需要真造一个 TB 卷来验证；
* `migrate` 会**真拷贝整卷**（1.5 GiB 的卷就写 1.5 GiB）⇒ 测试里只用小卷跑它；
* `shutil.copy` 会把稀疏文件的洞**实体化**（不管的话工作目录能涨到 ~935 MB）⇒ 所以跑完默认清掉。

|---|---|---|---|

| 2 | **递归往返** | 造目录树（子目录、空目录、空文件、带空格名、300 KB 大文件）→ `sftpcli put -r` 上传 → `get -r` 下回来 → 看差异 | `diff -r` 无差异；`get` 后位图与上传前一致 |
| 3 | **格式能力** | 调 `rt/feat.py`（**手工构造**块，不经过写入方）→ 看输出 | 输出含"全部通过" |
| 4 | **伸缩四方向** | `harness.make` 造卷 + 存快照 → 四个方向（右扩/左扩/右缩/左缩）各复制一份跑 `resize` 并 verify → 再造"缩到比已用还小"期望被拒 → 跑 `--dry-run` 比对不落盘 → 看结果 | 生成脚本输出 `RESULT=OK` |
| 5 | **fsck 病态卷** | 从 `base.img` 复制 3 份 → 分别造成 **leak**（多占一块）/ **miss**（位图漏标一块）/ **crc**（改坏数据）→ 逐个跑 `fsck -n` → **看退出码**；再对 `feat.img` 跑一次 | 退出码依次 **0 / 4 / 4 / 4 / 0** |
| 6 | **HTTP 服务器** | 起 `tool server`（内存卷）→ 发 `GET /` 与 `PUT` → 看状态码 | 200 / 2xx |
| 7 | **anchor v3** | 调 `anchor_v3.py`：先建卷读第 0 块看 tag（A1–A5），再故意破坏（A6 CRC / A7 头尾 `gen` 不一致 / A8 pool 段写垃圾 / A9 假 `easypool` / A10 dirty 往返）→ 看每项 | 输出里 ≥9 个 `True` |
| 8 | **shell 提示符** | 真 pty 起交互 shell → **逐行慢喂**（空格、空行、`ls /`、`pwd`、`quit`）→ 看提示符行数 | `通过 = True`（无双提示符、空输入不堆行）|

| 10 | **文档一致性** | 调 `doccheck.py` → 看汇总 | `发现问题 0 个` |
| 11 | **DIR_OBJECT 只读** | 调 `dirobj.py`（12 项）→ 看汇总 | 输出里没有 `FAIL` |

### 段 [1] 里的子检查（输出里叫 `1b`~`1g`）

| 子检查 | 流程（先 → 再 → 看） |
|---|---|
| **1b** | 遍历 `anchor_layout()` 的**全部 tag** → 逐个调 `resolve_anchor_tag()` → 看有没有解不出来的；delta 类（`rootioff` / `alloioff` / `peer`）必须解出地址 ✓ |
| **1c** | `--disk` 的三条保护：指向**普通文件** ⇒ 拒绝并给出正确指引 ✓；只读探测**真块设备** ⇒ 先打印盘信息 ✓；**写**真块设备 ⇒ 必须被拦（挂载中 / 权限 / 系统盘）✓ |
| **1d** | `--yes` / `--force` 归**会写盘的命令自己**（`mkfs` 有 ✓；`sftpcli` 的 `--force` 仍是"覆盖文件" ✓）→ 再用**真 pty** 给 `--disk` 的确认喂 `n`（应取消）和 `y`（应继续）✓ |
| **1e** | 分区 = **自动加偏移**：造 MBR 镜像 → `mkfs --part 1` → 看**磁盘绝对 1 MiB 处 == 卷内偏移 0** ✓、MBR 签名 `55AA` 还在 ✓、`--part 1` 与 `--offs 1M` 读到同一批字节 ✓ |
| **1f** | `mbr --seteasy` / `gpt --seteasy`：只改目标分区 ✓、数据逐字节未动 ✓、**不带 `--seteasy` 只列不写** ✓、GPT 主备头 + 项数组 CRC 自洽 ✓、形态不匹配（`mbr` 用在 GPT 上）报错 ✓ |
| **1h** | `mbr --create` / `gpt --create`：在空容器上建表 + 一个占满的分区 → 看类型是不是我们的（MBR `0x7F` / GPT 我们的 GUID + 名字 `EasyFS`）✓、重复建要 `--force` ✓、四步流水线（`vdisk --create` → `gpt --create` → `mkfs --part 1` → `fsck`）✓、`parted` 也认 ✓ |
| **1j** | `resize`：不带 `--yes` ⇒ 非交互下**拒绝**（提示 `--yes`）✓；带 `--yes` ⇒ 不问、直接做（打印"变化"）✓；`--part N` 代替 `--offs/--size`（旧几何取自分区，输出里标了"MBR 分区 #1"）✓；两者混用 ⇒ 报错 ✓ |
| **1i** | 真盘路径（本机没有可写盘 ⇒ 把普通文件"骗"成块设备）：`--disk` 三步（建表 / 打标识 / 建卷）都跑通 ✓；`--create` 警告的是"**重建整张分区表**"、`--seteasy` 是"只改分区类型" ✓；**真 pty** 里喂 `n` ⇒ 取消**且一个字节都没写** ✓、喂 `y` ⇒ 才真写 ✓ |
| **1g** | `vdisk`：四种后缀各建一个 → 看详情里的格式对不对 ✓；重复 `--create` 要 `--force` ✓；`.vmdk` 当卷载体建卷 + `fsck` 干净 ✓；`.dmg` 当载体被拒 ✓；**有 `qemu-img` 就交叉验证**（它也得认得我们建的 `vmdk` / `dmg` ✓，并能完整读出 dmg 数据 ✓）|

## 各独立脚本测什么（都能单独跑）

| 文件 | 流程（先 → 再 → 看） |
|---|---|
| `doccheck.py` | 读全部 `doc/*.md` → 逐条比对 14 项（索引覆盖 / 链接与锚点 / 属性注册表 ↔ 代码 / 块类型表 ↔ 代码 / 陈旧用语 / 跨文档与本文内 `§` 引用 / 章节重号·跳号）→ 打印"发现问题 N 个" |
| `anchor_v3.py` | `mkfs` 建 8 MiB 卷 → 直接读第 0 块解 tag（A1 魔数+版本串、A2 `hdrbytes`、A3 两份 `hdrcrc`、A4 裸 16 字节 uuid、A5 非池成员）→ 再复制几份**故意破坏**（A6 改字段不修 CRC ⇒ 该份不可用、回落另一份；A7 头尾 `gen` 不一致 ⇒ `ESTALE`；A8 pool 段乱写 ⇒ 仍能挂载；A9 假 `easypool` ⇒ `poolcrc` 不匹配；A10 dirty 往返）→ 看每行 `True` |
| `mixed.py` | ① 纯算选型（1 TiB / 16 TiB / `--fixbitsize 4K`·`64K`，**不落盘**）→ ② 真建 1 GiB 卷：挂载、空闲账、写 5 个小文件、`fsck` → ③ 一直写 4 KiB 文件**填满细粒度子区域**，逼出自动分裂 → ④ 1 GiB ↔ 1.5 GiB 扩缩 → ⑤ 写 40 个文件再全删（元数据不会自动回收）→ `optimize alloc --dry-run` 与实跑 → ⑥ 查"一个 bit 一主"（分配块与根目录块不共用粗 bit）与分裂次数上界 → 最后看 `ALL = True` |
| `dirobj.py` | 建卷并写子目录 → 取出它的 dir 链块 → **手工**造一个对象块（载荷 = 内容块表 `DATA_PTR × n`）→ 把子目录条目改成 `DIR_OBJECT` 形态 → 重新挂载读 → 看 12 项（目录内容对不对、块表顺序生效、顺序错报错、指向非 dir 报错、空块表报错、写对象目录 ⇒ `ENOTSUP` …）|
| `shell_prompt.py` | 没有卷就先 `mkfs` 一个 16 MiB 的 → 真 pty 起 shell → **逐行慢喂**三种输入（`" "`、`""`、`"   "`）再喂 `ls /`、`pwd`、`quit` → 看：提示符行数 = 输入行数、同一行不出现两个提示符、纯空提示符行 = 空输入的个数 |
| `rt/feat.py` | 手工拼 14 种格式场景（硬链接 `NLINK=2` + 两个名字、跨块条目 `span.bin`、软链接两种编码、`PAD1`/`PADn` 跳过、对象块）→ 直接读回验证 + 重新挂载再验 → 看"全部通过" |
| `rt/harness.py` | **工具模块**（不是测试）：`make(路径)` 造卷、`snapshot(路径, offs, size)` 存快照、`run(路径, 旧几何, 新几何, verify=True)` 跑一次 resize 并自检 —— 被 `run_all.py` 和它生成的 `rz.py` 调用 |

## 约定（加用例时请遵守）

**放哪儿**（重要）：

* **常用 / 可复用的测试 → `test/`**（能被 `run_all.py` 调起来、能单独跑、路径按 `__file__` 推导）✓
* **临时 / 一次性脚本 → `/tmp`**（会话用完就扔，**不要**进仓库、也别在 `test/` 里留半成品）✓
* 测试产生的镜像放工作目录（默认 `test/.work/`，已 gitignore ✓；`EASYFS_TEST_DIR` 可改到 `/tmp`）✓


* 断言写法：`ok.append((描述, True/False))`，最后**只打印一次** `ALL = ...`
  （多个 `ALL = True` 会让上层断言"看起来过了"其实漏跑 —— 踩过 ✓）；
* 每个脚本都要能**单独跑**：路径按 `__file__` 推导，不要写死仓库路径或 `/tmp/xxx.img`；
* 新用例优先放进 `mixed.py` / `anchor_v3.py` 这类**主题文件**，只有跨主题的才进 `run_all.py`；
* 落盘卷 ≤ 1.5 GiB；大卷只做纯算。
