# EasyFS

极简、可移植、可双向伸缩的文件系统。同一份 4 KiB 块格式：先用 Python 在 x86 上跑通，
再往 ESP32 / STM32 / 裸机移植。载体可以是块设备、内存块，或文件里的一段区域 ——
只要求载体能按偏移读、写（擦除 / 磨损均衡都在设备层之下）。命令行像 sftp（`ls` / `cd` / `put` / `get`）。
